## LLM wiki

This repository is an LLM-maintained wiki. For each workflow, run its guide and follow
it: `wiki guide ingest` (add a source from `raw/`), `wiki guide query` (answer a question
from the wiki), `wiki guide lint` (audit the wiki); `wiki guide` lists them. Use the
`wiki` command (`wiki search`, `wiki list`, `wiki neighbors`) instead of grepping pages.
Never edit anything in `raw/`.
