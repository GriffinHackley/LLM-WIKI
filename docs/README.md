# Docs

Which page you need depends on what you are after.

## Learn

- **[Getting started](getting-started.md):** install the tool and set up a wiki: a
  research wiki, a wiki about a codebase, a wiki for your writing, or a folder of notes
  you already keep.
- **[Concepts](concepts.md):** how the pieces fit together, what each term means, and
  what the kit does not do.

## Do

- **[Workflows](workflows.md):** what you do with a wiki, step by step: ask it questions,
  keep it healthy, find its gaps, and each preset's own workflows, from a code task to a
  writing session.

## Look up

- **[Commands](commands.md):** every command and option, with examples.
- **[Config](config.md):** every setting in `.wiki-cli.toml`, and how to review a drafted
  config.
- **[Presets](presets.md):** what each preset is for, and its page types.
- **[Guides](guides.md):** the steps agents follow, and how to customise them: your own
  rules, parts, guides and page types.
- **[Troubleshooting](troubleshooting.md):** what a message means, and what to do.

## Understand

- **[Navigation](navigation.md):** how an agent answers a question while reading as
  little as possible.
- **[Evaluating search](evaluation.md):** measure how well search finds the right pages
  in your own wiki.
- **[Model selection](model-selection.md):** why the default models were chosen, and
  how they compare.
