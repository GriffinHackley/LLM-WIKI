## Code wiki

This repository is an LLM-maintained wiki about the code at `{{code_repo}}`. For each
workflow, run its guide once and carry out the steps it prints yourself:

- `wiki guide ingest`: document part of the code
- `wiki guide sync`: update the wiki after the code changed
- `wiki guide query`: answer a question from the wiki
- `wiki guide lint`: audit the wiki

`wiki guide` lists them.
